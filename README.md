# 🚀 DayFlow — Unified HRMS Enterprise Portal

> A modern, human-centered enterprise Human Resource Management System (HRMS) built with **React 18 + TypeScript + Vite + Tailwind CSS**, based on the Google Stitch UI design system.

---

## ✨ Features

### 🏢 **1. Admin Operations Hub**
* **Workforce Pulse**: Real-time presence vs. absence counters, punctuality metrics, and employee roster stats.
* **Leave & PTO Approvals**: One-click review, approve, or reject employee time-off requests with real-time audit logs.
* **Department Breakdown**: Visual distribution of headcount, leadership, and budget allocation across Engineering, Design, Product, HR, and Finance.

### 👤 **2. Employee Self-Service Portal**
* **Live Punch Clock**: Real-time shift tracking with interactive punch-in/out and shift completion progress gauge.
* **Leave Balances**: Visual quota meters for Casual, Sick, Annual, and Parental leaves.
* **Instant Time-Off Application**: Auto-calculated duration with instant submission.
* **Salary Slips**: View and print monthly payslips with detailed earnings and tax deductions.

### 👥 **3. Comprehensive Employee Directory**
* **Multi-View Modes**: Switch between responsive Grid Cards and high-density Table views.
* **Faceted Filtering**: Search and filter by department, role, location, and employment status (Active, On Leave, Probation).
* **Profile Drawer & Persona Switcher**: Inspect detailed profiles and switch active personas directly from the UI.

### ⏱️ **4. Attendance & Timesheets**
* **Daily Punch Records**: Track check-in, check-out, active work hours, and overtime.
* **Punctuality Status**: Visual badges for `Present`, `Late Arrival`, `Half Day`, `On Leave`, and `Absent`.
* **Exportable Timesheets**: One-click CSV timesheet export.

### 💳 **5. Automated Payroll Management**
* **Monthly Disbursement Cycles**: Total net payouts, gross salaries, taxes, and PF calculations.
* **Interactive Payslip Generator**: Printable salary slips formatted for enterprise distribution.
* **Disbursement Status**: Batch approval and marking as Paid.

### 📊 **6. Workforce Analytics & Reports**
* **Interactive Visualizations (Recharts)**:
  * Monthly Attendance & Punctuality trend (Area chart)
  * Department Headcount distribution (Donut chart)
  * Payroll & compensation evolution (Stacked Bar chart)

### ⚙️ **7. Portal Governance & Settings**
* Company profile configuration, working hours/shift rules, leave quota limits, and email alert preferences.

## 🛠️ Tech Stack

* **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Dayflow design system tokens
* **Icons**: [Lucide React](https://lucide.dev/)
* **Routing**: [React Router v6](https://reactrouter.com/)
* **Charts**: [Recharts](https://recharts.org/)
* **Design Specification**: Dayflow Modern HRMS (Google Stitch)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Manav373/DayFlow.git
cd DayFlow
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
